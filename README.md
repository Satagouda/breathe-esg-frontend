# Breathe ESG Frontend

Frontend application for the Breathe ESG technical assignment.

This application provides:
- ESG ingestion workflows
- Analyst review dashboards
- Emissions analytics
- Audit-ready record review
- Multi-source upload experience

Built using React + Vite with a modern TailwindCSS-based UI.
